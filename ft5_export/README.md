# FT5 の日足をアプリへ書き出す

アプリの日足データの土台は、FT5 が EA のために作った日足そのものです(`../data/ft5_daily.json`)。
毎朝のスクショ取り込みと手動補正が、これより優先されます。

## 手順(この順番で)

1. FT5 で全ペアのデータを更新する。
2. **TimeZone=2 / DST=1 のプロジェクト**(例: `v5`)を開いて実行する。
   このとき、D1キャッシュ(`C:\ForexTester5\data\Testing\<SYM>\1440\Bars.dat`)が NY17:00 区切りで作り直されます。
3. `update_and_push.ps1` を右クリック →「PowerShellで実行」。
   `export_daily.py` で書き出し、変更があれば GitHub に push します。
   数十秒〜数分で公開ページに反映されます。

## 仕組みと注意

- `export_daily.py` は D1 キャッシュを直接読みます。GBPJPY/GBPUSD/USDJPY/AUDJPY/EURJPY の直近120本が対象です。
- **D1キャッシュの日付ラベルは1営業日進んでいます**(セッション終了日で付いている)。
  書き出し時に、セッション開始日(ブローカー・EA の OpenTime と同じ基準)へずらしています。
- TimeZone=0 のプロジェクトを最後に開くと、キャッシュがカレンダー日区切りに置き換わります。
  そのため書き出し前に「直近1年に土日の足が無いか」を検査し、あれば中止します。
- 最後の足が未確定の場合(当日のセッション中にFT5を動かしたとき)は、自動で除きます。
