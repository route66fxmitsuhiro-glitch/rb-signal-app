# RBシグナル(v5)

GBP/JPY を中心とした日足システムトレード **v5**(EA `RB_Broker_Exec730v5`)の判定を、
スマホで毎朝確認して**手で発注する**ための PWA です。
公開先: https://route66fxmitsuhiro-glitch.github.io/rb-signal-app/

## 何をするアプリか

- **コア**(GBPJPY/GBPUSD/USDJPY)
  - 日足 RideThin(5トランシェ)と週足ドンチャン(3階層)のシグナル、ロット、目標、撤退ラインを表示します。
- **分散レイヤー11層**(GBPJPY 4層 / GBPUSD 1層 / USDJPY 3層 / AUDJPY 2層 / EURJPY 1層)
  - 方向、ロット、固定逆指値、時間切れ日を表示します。
  - 衝突ゲートも反映します(同じペアの他の層が逆向きに保有中ならロット×0.35。ピンバー2層は対象外)。
  - 保有中の層は、シグナルの有無にかかわらず「保有中」と表示します。
- **執行時刻**: 日足確定(NY17:00 = 日本時間 夏6:00/冬7:00)の **90分後、夏7:30/冬8:30** です。
  画面上部に常に表示します。ロールオーバー直後はスプレッドが大きく開くためです。
- **ロット**
  - v5 のバックテストの最大DD(確定損益ベース 3,024 USD)が「運用資金 × DD許容度」に収まるように、全層を一律に縮尺します。
  - **含み損込みの最大DDはその約1.68倍**です。口座の評価額で 20% までと考えるなら、DD許容度は 12% 前後にします。
- **フォワード記録**(`forward.html`)
  - フォワード検証の判定を表示します(件数500/1,000/2,000/4,000での WATCH/STOP 基準)。
  - 執行時のスプレッドを記録できます。
  - 実績とバックテストの期間別分布を比べます。実行率とレイヤー別成績も出します。
  - 約定履歴のスクショから、決済価格を AI で読み取れます。

判定ロジックはすべて `signal-core.js` にあります。
23年分の EA 実機ログと照合した一致率は、**コア 99.9% / 衛星 99.4%** です。

**v5 はフォワード検証中です。パラメータ・層・ロット比・執行時刻は変更しません**
(全層一律のロット縮尺だけは可)。基準はプロジェクトの `docs/history/13_forward_protocol_2026-09-26.md` にあります。

## できないこと

- 自動発注はしません。表示を見て、自分でブローカーに発注してください。
- 自動通知はありません(2026-09-23に廃止)。
  判定に使う4本値が端末の中にしか無いので、通知する側からは見えないためです。
- ride サーキットブレーカーは実装していません。EA 側でも、ロットの最小値に当たって事実上動いていません。

## 毎朝の使い方

1. **05:30〜06:00(冬 06:30〜07:00)**に、ブローカー(GMOクリック証券)のレート一覧をスクショして「前日バーの取り込み」に入れる。
   金曜の足は、土曜〜月曜の朝ならいつでも撮れます。
2. 「本日の判定を取得」を押す。
3. **7:30(冬 8:30)以降**に成行で発注し、「このシグナルを記録」で実際の約定価格を入れる。
4. フォワード記録ページで、その時点のスプレッドを記録する。
5. 決済したらトランシェにチェックを入れ、決済価格を入れる。

## データの優先順位

スクショ・手動補正 > FT5 エクスポート(`data/ft5_daily.json`)> Twelve Data(1時間足から NY17:00 区切りで組み直し)。
FT5 データの更新手順は `ft5_export/README.md` にあります。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` / `app.js` / `style.css` | メイン画面(判定・保有・注文チェック) |
| `signal-core.js` | 判定ロジック(全ページ共通) |
| `forward.html` / `forward.js` / `forward-ref.js` | フォワード記録。`forward-ref.js` は `conflictaware/aplus/forward_reference_v5.py` で生成 |
| `edit-bars.html` / `edit-bars.js` | 直近の日足4本値の手動補正 |
| `sw.js` | オフライン用の Service Worker。**更新のたびに `CACHE_NAME` を上げる**(新版は起動時に自動で1回再読み込みされる) |
| `ft5_export/` | FT5 の日足をこのアプリ用に書き出すスクリプト |

設定・保有記録はすべて端末のブラウザ(localStorage)にだけ保存されます。
外部に送るのは、Twelve Data への価格取得と、AI 読み取りを使うときの Anthropic API だけです。
